# Authored examples

- landing-page is an intentionally weak static fixture for narrow source repairs
  and a concrete heading improvement. npm run demo copies it before editing.
- application is a small static form for contextual state/journey review. It has
  no server and does not claim connected export functionality.
- writing contains labelled synthetic copy with vague and unsupported claims.
- backend contains deliberately suspicious source patterns. Do not execute it.
- hooks contains deterministic protocol examples scoped to the landing fixture.

These examples contain no real customers, testimonials or secret values. Browser,
provider and production acceptance are not established by these fixtures.
