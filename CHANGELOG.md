# Changelog

## 0.3.0

- Added eight contextual visual-quality criteria for palette, typography, composition, imagery, surfaces, component coherence, states and product character.
- Added an optional validated design brief, shared by plans, reviewers and fixers and bound to the current input digest.
- Kept visual taste unassessed until supported by actual rendered review; no new automatic taste score or style bans.
- Included the complete 196-item release checklist, preserving its original 188 prompts.

## 0.2.0

- Renamed the project, public repository, package, skill and CLI to sloppyai.
- Updated commands, hook environment variables, configuration, report paths and documentation to the new name.
- Preserved the earlier release and kept its private report directories excluded from scans and version control.

## 0.1.0

- Portable artifact-quality skill with plan, audit, improve and verify workflows.
- Complete 194-entry catalogue including all 102 original reference labels.
- Static source checks, evidence-bound review import and separate domain ratings.
- Bounded repair/recheck loops, change-triggered watch and optional reviewer/fixer hooks.
- Recorded command retries, regression/no-progress stops and private issue history.
- Narrow source repairs, private backups and conflict-aware undo.
- Self-contained CLI/library bundles, managed install/remove, schemas and examples.
