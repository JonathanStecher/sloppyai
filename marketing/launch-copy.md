## Short announcement

Remove AI slop from what you build. sloppyai helps your coding agent improve
design and writing, fix bugs and security issues, and show what changed.

Get started: https://github.com/JonathanStecher/sloppyai

## Longer announcement

Your AI-built project has a first version. Now make it easier to use and more
reliable.

sloppyai helps your coding agent work on the project you already have: clearer
interfaces, specific writing, working user flows, and repairs for bugs and
supported security findings. It keeps useful features and deliberate style choices
part of the brief.

Start with an audit or ask for improvements. After each round, review the changes,
the checks that ran, the ratings and the issues that still need attention.

The project is open source and includes a portable skill, local CLI,
documentation and a runnable example.

Try it: https://github.com/JonathanStecher/sloppyai

## Blog or newsletter introduction

sloppyai is an open-source skill for improving websites, apps and content made
with AI. Bring an existing project to your coding agent and ask for clearer
design, better writing, bug fixes and security repairs. The
[getting-started article](../blog/how-to-use-sloppyai.md) shows the installation,
the prompt to use and how to inspect the result.

## Demo caption

In the included landing-page example, sloppyai removes restrictive zoom settings,
adds the configured document language, makes the new-tab relationship explicit,
and replaces a vague headline with “Export a report.”

The run goes from four findings to zero. Its fixture-specific copy rating moves
from 2/5 to 4/5. Save, Cancel and the reference link remain in the example.

These figures describe the authored demonstration. The demo uses deterministic
hooks for that heading task; it is not a general writing benchmark or a customer
result. Run it yourself with `npm run demo:hooks` from the repository checkout.
