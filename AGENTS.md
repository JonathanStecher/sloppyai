# Working on Craftcheck

Read README.md, then the workflow or module you will change. The installable
skill is under skills/craftcheck. Source code is under src. Build output in
skills/craftcheck/scripts is generated by scripts/build.mjs; edit source first.

- Preserve the user's artifact, useful features, public contracts and accepted style.
- Taste is contextual. Fonts, gradients, cards and punctuation do not prove AI authorship.
- Keep severity, evidence, confidence, coverage and verification separate.
- Never turn a skipped check, absent tool, stale review or successful command into a clean audit.
- Default scans read files only. Project commands and repair hooks require explicit execution authorization.
- Keep retries bounded. Stop on regression, no progress, cancellation or budget exhaustion.
- Do not expose source secrets in reports, errors, command output or fixtures.
- Keep the installed skill self-contained. Load only relevant reference material.
- Add meaningful regression tests for changed behaviour, including legitimate counterexamples.
- Keep canonical catalogue text in catalog records; generate docs/catalog.md.

Run npm run check before release. Run npm pack and exercise the installed tarball
when changing packaging, scripts or installation. Do not assert host or browser
verification that was not actually performed.
